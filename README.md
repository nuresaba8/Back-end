📈 Stock Market Data Management System
A stock market data management system built to handle both real-time and historical market data efficiently. The platform supports full CRUD operations for stock entries and uses a layered architecture with Entity Framework (Database First) and SQL Server for persistent storage. The backend is powered by ASP.NET Web API, with a role-based repository pattern to keep data access modular and maintainable. The system includes robust error handling, logging, and is designed with scalability in mind.

Tech Stack:

⚙️ ASP.NET Web API

🌐 Next.js

🎨 Tailwind CSS
